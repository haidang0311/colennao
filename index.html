Mã Nguồn Java (Spring Boot & Servlet)

Dùng để chạy trang web HTML này trên máy chủ Java thực tế

💡 Hướng dẫn sử dụng nhanh:

  • Cách 1 (Đơn giản nhất): Đặt file index.html này vào thư mục src/main/resources/static/ hoặc src/main/resources/templates/ trong dự án Java Spring Boot của bạn.
  • Cách 2 (Xử lý ngẫu nhiên từ phía Server Java): Sử dụng Controller Java dưới đây để mỗi lần người dùng truy cập http://localhost:8080/, Java sẽ chọn ngẫu nhiên lời chúc và chú mèo rồi truyền sang giao diện HTML.
CuteStudyController.java (Spring Boot) 
package com.meowstudy.app;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.ResponseBody;

import java.util.Arrays;
import java.util.List;
import java.util.Random;

@SpringBootApplication
@Controller
public class CuteStudyApplication {

    public static void main(String[] args) {
        SpringApplication.run(CuteStudyApplication.class, args);
        System.out.println("🌸 Server Góc Học Tập Mèo Nhỏ đã chạy tại: http://localhost:8080 🌸");
    }

    // Danh sách lời chúc động viên học tập dễ thương
    private static final List<String> WISHES = Arrays.asList(
        "Cố lên cô gái nhỏ! Mỗi trang sách cậu đọc hôm nay đều là một viên gạch hồng xây nên ước mơ rực rỡ ngày mai đó! 🌸",
        "Đừng áp lực quá nhé! Mèo nhỏ tin rằng sự chăm chỉ và dịu dàng của cậu sẽ mang lại kết quả ngọt ngào nhất! 🍓",
        "Hôm nay cậu đã vất vả nhiều rồi. Uống một ngụm nước ấm, vươn vai một cái rồi mình cùng chinh phục bài học tiếp theo nha! 🐾",
        "Điểm số không định nghĩa tất cả, nhưng nỗ lực của cậu lúc này thực sự tỏa sáng lấp lánh như vì sao vậy! ✨",
        "Chỉ cần hôm nay cậu giỏi hơn ngày hôm qua một chút xíu thôi là đã xứng đáng được thưởng 100 cái xoa đầu rồi! 🎀"
    );

    // API trả về dữ liệu JSON ngẫu nhiên mỗi lần truy cập hoặc gọi AJAX
    @GetMapping("/api/random-cheer")
    @ResponseBody
    public CheerResponse getRandomCheer() {
        Random random = new Random();
        String randomWish = WISHES.get(random.nextInt(WISHES.size()));
        String catImageUrl = "https://cataas.com/cat/cute?t=" + System.currentTimeMillis();
        return new CheerResponse(randomWish, catImageUrl, "Mèo Bông Gòn Đáng Yêu");
    }

    // Class chứa dữ liệu trả về
    static class CheerResponse {
        public String wish;
        public String catUrl;
        public String catName;

        public CheerResponse(String wish, String catUrl, String catName) {
            this.wish = wish;
            this.catUrl = catUrl;
            this.catName = catName;
        }
    }
}

Cách Tạo Link Gửi Cho Người Khác

Miễn phí 100% - Ai bấm vào link cũng xem được trên điện thoại & máy tính

BƯỚC 1

Tải trang web này thành file index.html

Bấm nút bên cạnh để tải tự động file hoàn chỉnh về máy của bạn.

BƯỚC 2: CHỌN 1 CÁCH ĐỂ LẤY LINK ONLINE

⚡ Cách 1: Kéo thả lấy link trong 30 giây (Khuyên dùng)

Dễ nhất
  1. Truy cập trang app.netlify.com/drop hoặc tiiny.host.
  2. Tạo một thư mục mới trên máy tính, bỏ file index.html vừa tải ở Bước 1 vào trong thư mục đó.
  3. Kéo thả thư mục đó vào trang web trên. Ngay lập tức bạn sẽ nhận được 1 đường link (VD: https://meo-hoc-tap.netlify.app) để gửi qua Zalo, Messenger!

🌸 Cách 2: Dùng GitHub Pages (Link đẹp, vĩnh viễn)

  1. Đăng nhập GitHub.com, bấm New Repository (đặt tên ví dụ: goc-hoc-tap).
  2. Bấm Upload an existing file rồi tải file index.html lên và bấm Commit changes.
  3. Vào mục Settings → Pages → ở mục Branch chọn main rồi bấm Save. Đợi 1 phút là có link dạng https://ten-ban.github.io/goc-hoc-tap/.

☕ Cách 3: Nếu bạn đang chạy bằng Java trên máy tính

Khi chạy project Java ở cổng localhost:8080, bạn chỉ cần cài công cụ miễn phí ngrok và gõ lệnh: ngrok http 8080. Ngrok sẽ cấp ngay cho bạn 1 đường link dạng https://xxxx.ngrok-free.app để người khác truy cập thẳng vào server Java của bạn!
